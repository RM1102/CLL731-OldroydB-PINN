# The paper

Boyko, E. & Stone, H. A. (2022). Pressure-driven flow of the viscoelastic Oldroyd-B fluid in narrow non-uniform geometries: analytical results and comparison with simulations. *Journal of Fluid Mechanics* 936, A23.

* Journal: https://doi.org/10.1017/jfm.2022.67
* Free preprint (arXiv): https://arxiv.org/abs/2109.06928

The PDF is not stored in this repository (copyright). Only `03_code/scripts/digitize_fe_data.py` needs it. To re-run that script, save the arXiv PDF here as
`Boyko_Stone_2022_JFM_OldroydB_narrow_channels_arXiv2109.06928.pdf`, for example with

```bash
curl -L -o Boyko_Stone_2022_JFM_OldroydB_narrow_channels_arXiv2109.06928.pdf https://arxiv.org/pdf/2109.06928
```

The data it extracts are already saved in `04_results/digitized/`.
